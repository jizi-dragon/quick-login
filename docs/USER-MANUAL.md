# QuickLogin 用户手册

> 版本：v3.9.2 · 适用对象：日常使用者 · 技术实现细节见 `docs/PROJECT-STATUS.md` 与 `docs/CODEBASE_OVERVIEW.md`

---

## 一、这是什么

**QuickLogin** 是一个 Chrome 浏览器扩展，让你在**同一个浏览器窗口**里同时登录并使用**同一网站的多个账号**——每个账号拥有自己的标签页、独立的登录状态与存储空间，互不干扰、互不登出。

典型场景：一个管理员账号 + 多个普通业务账号并行在线；切换账号不用反复输密码登进登出。

---

## 二、安装与装载

1. 构建产物在仓库根目录的 **`dist/`** 文件夹（拿到发行包则解压）；
2. 打开 Chrome，地址栏输入 `chrome://extensions`，右上角打开**开发者模式**；
3. 点左上角**「加载已解压的扩展程序」**，选择 `dist/` 文件夹；
4. 工具栏出现 QuickLogin 图标即安装成功。

⚠️ **重要**：每次更新代码/构建后，必须在 `chrome://extensions` 的扩展卡片上点**「重新加载」（↻）**。Chrome 会缓存扩展的 Service Worker 脚本，不点重新加载会一直运行旧版本——很多「功能没生效」都是这个原因。

---

## 三、五分钟上手

1. 点工具栏 QuickLogin 图标 → 点**「打开并行管理页」**；
2. 在**「站点管理」**里输入目标网站的域名（如 `example.com`）→ 点**「添加并授权」**（只有授权过的站点才会启用多账号隔离）；
3. 在**「添加并行账号」**里选择站点、填写**账号名与密码**（页签名、盒子可留空）→ 点**「添加并打开」**；
4. 新标签页打开目标网站并**自动填表登录**；登录成功后该账号在线，标签标题显示你自定义的页签名；
5. 重复第 3 步添加更多账号；按 **Alt+Q**（默认）呼出**账号轮盘**随时切换焦点。

## 四、功能点详解

### 4.1 启动弹窗（工具栏图标）

- **打开并行管理页**：进入主工作台；
- 底部统计条实时显示：账号总数 / 在线数 / 已授权站点数。

### 4.2 并行管理页（主工作台）

顶部统计：**账号数 · 在线数 · 盒子数**。

**账号卡片**（每账号一张）：

| 操作 | 说明 |
|---|---|
| **打开 / 聚焦标签页** | 已在线则跳到其标签页，未在线则打开并自动登录 |
| **新标签页** | 为该账号再开一个同站标签页（同一身份） |
| **改页签名** | 修改该账号所有标签页的标题（便于区分账号） |
| **移入盒子** | 把该账号移入某个盒子（见 4.3） |
| **删除** | 删除账号记录，并关闭其所有并行标签页 |

卡片左上角彩色竖条与头像 = 账号专属配色；右上角**状态徽标**：
`在线 ×N`（已登录，N 为打开的标签数）· `待登录`（标签已开，等待登录完成）· `离线` · `未授权 · 已暂停`（站点授权被移除，账号暂停使用）。

**添加并行账号表单**：

- **站点**：从已授权站点中选择；
- **盒子**：新账号直接归入某个盒子；
- **页签名**：自定义标签标题，可省略（默认用账号名）；
- **账号名 / 密码**：密码以 **AES-GCM 加密保存在本机**，不上传任何服务器；
- **仅保存**：只保存不打开；**添加并打开**：保存并立即开标签页自动登录；
- **批量导入**：展开文本框，每行一条 `页签名,账号名,密码`（也支持整段 JSON 数组），点「解析并导入」批量建号——导入到表单当前所选的站点与盒子。

### 4.3 盒子系统（账号收纳）

盒子是账号的分组容器，轮盘翻页也按盒子进行：

- **筛选**：点击顶部盒子 chips（`全部 / 默认盒子 / 各盒子`）筛选账号列表，chip 上的数字 = 该盒账号数；
- **＋新建盒子**：chips 行末的虚线按钮，输入名字即创建（空盒子也保留）；
- **✎ 重命名**：鼠标悬停在盒子 chip 上浮现——普通盒子：盒内账号**自动随迁**；输入的名字与已有盒子相同则**并入**那个盒子（会二次确认）。**默认盒子也能改名**：未归盒账号即时显示新名称，且不影响任何账号数据；改名与其它盒子重名时会被拒绝；
- **✕ 删除**：悬停浮现——空盒直接删除；盒内还有账号时先确认（提示 N 个账号将回到默认盒子），账号自动回归**默认盒子**；
- **默认盒子**：未归盒账号的归宿，**可重命名、不可删除**（悬停有提示）。

### 4.4 批量管理

- 点右上角**「批量管理」**进入批量模式：每张账号卡片出现勾选框；
- 工具条支持：**移入盒子…**（把所选账号批量移入某个盒子，弹窗列出实际存在的盒子，也可输入新盒子名一步创建）、**删除所选**（连带关闭其所有标签页）、**取消选择**；
- 再点**「退出批量」**返回普通模式。

### 4.5 站点管理

- **添加并授权**：输入域名（不含 `https://`）授权。只有授权过的站点才会安装隔离规则（改写鉴权头、分隔存储）；
- **移除**：取消授权后，该站点不再生效隔离（新导航开始），相关账号显示「未授权 · 已暂停」。

### 4.6 账号轮盘（快捷切换）

- **呼出**：按 **Alt+Q**（可在 `chrome://extensions/shortcuts` 自定义）；
- **形态**：普通网页上直接在页面内展开圆环形浮层；受限页面（如浏览器设置页）自动降级为独立小窗；
- **选择账号**：悬停高亮扇区 → 点击切换；或直接按 **数字键 1-9、0** 快选；
- **切换盒子**：**滚轮**或**点击中心 Hub** 循环切换盒子——单环只显示当前盒子的账号，Hub 显示盒名与在线汇总，外圈进度弧指示盒子序位；空盒子页会提示「该盒子暂无账号」；
- **关闭**：Esc、再次按快捷键、或点击浮层外的遮罩。

### 4.7 自动登录与免密恢复

- **添加并打开**：扩展自动填入账号名密码并提交（表单自动填表）；
- **再次打开在线账号**：直接复用已捕获的登录态，**免密直达**，无需重输密码；
- 浏览器重启后，从管理页点「打开」同样免密恢复（登录态快照保存在本机会话存储中）。

## 五、它如何隔离账号（六平面简介）

同一网站的多份登录态本质上是共享资源的叠加，QuickLogin 在六个层面逐一切断串扰：

1. **存储**——每账号的 localStorage 重定向到专属命名空间，Cookie 虚拟化为账号「Cookie 袋」；
2. **鉴权头**——每个标签页的网络请求被强制改写为该账号自己的令牌；
3. **Cookie**——出站 Cookie 按账号回放各自的登录快照；
4. **缓存**——同站 GET 请求按标签页硬分区，共享缓存不会串内容；
5. **Service Worker / CacheStorage**——封控站点的 SW 注册与缓存命名空间；
6. **IndexedDB**——站点数据库按账号前缀隔离（这是多账号串号最常见的载体）。

对你的体感就是：**每个标签页是一个完全独立的「分身浏览器」**。

## 六、数据与安全

- 密码 **AES-GCM 加密存放本机**，任何服务器（包括扩展作者）都拿不到；
- 登录令牌快照保存在浏览器**会话级存储**中，关闭浏览器即清空；
- 扩展只在**你明确授权过的站点**上生效；
- 安全边界声明：扩展保证的是**客户端呈现层的账户分离**；若平台服务端本身存在越权缺陷（例如某账号能读到他人数据），应向平台方反馈。

## 七、常见问题（FAQ）

**Q1：明明是最新代码，功能却没生效？**
A：九成是没点**「重新加载」**。到 `chrome://extensions` 点扩展卡片上的 ↻；仍不行就「移除」后重新加载 `dist/`。

**Q2：能同时打开同一个账号的多个标签页吗？**
A：可以。卡片上点「新标签页」，同一身份多页并行。

**Q3：账号会互相登出吗？**
A：正常不会——这正是六平面隔离的职责。若某站点强制「单设备登录」，后登录的会把先登录的顶下线，这是站点侧行为。

**Q4：删除盒子会删掉账号吗？**
A：不会。盒内账号自动回到「默认盒子」，需要删账号请用卡片「删除」或批量「删除所选」。

**Q5：轮盘按 Alt+Q 没反应？**
A：检查该页面是否为受限页（扩展会自动改弹独立小窗，注意任务栏）；或在 `chrome://extensions/shortcuts` 里检查/重设快捷键。

**Q6：换电脑数据还在吗？**
A：账号与加密密码存放在本机浏览器配置中，不随扩展迁移；换机器需重新添加。

## 八、已知边界

- Web Worker 内打开的 IndexedDB 不受隔离补丁覆盖（罕见路径，待观测）；
- Cookie 快照在登录时点采集一次；若站点在会话中途轮换会话标识，该账号需重新登录一次以刷新快照（令牌本身不受影响）；
- 轮盘页面内浮层需要站点授权，未授权站点自动降级为独立小窗。
