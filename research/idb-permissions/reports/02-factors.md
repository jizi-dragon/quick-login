# 报告 02 · 影响账号权限的因素 × 影响账号安全的因素

生成：2026-08-28 · 依据：研究快照（snap-001/002/003/004）、LS dump、APITEST 两轮、JWT 载荷解析

## 一、影响「账号权限」的因素（谁决定了你能看到/做到什么）

### 服务端持有（真正的权限边界）
| 因素 | 证据 | 说明 |
|---|---|---|
| JWT 身份声明 | `nameidentifier`（账号 GUID）、`name`、`client_id`、`AuthCode`、`LoginAuthType`、`exp`、`iss:AksoAuth` | 权限判定锚点是账号 GUID；**JWT 内无 role/power 字段**——权限不在令牌里，服务端按 GUID 实时查配置 |
| 账号级权限配置 | 用户口述：菜单级、对象级、**字段级**；管理端为独立参数且管理端内再分级 | 客户端**未发现**该矩阵的存储本体（`user_center_power`="2" 两账号相同，为版本标记而非矩阵）→ 细粒度权限纯服务端逐请求判定 |
| 用户自有数据作用域 | 通知未读数 U=57 / A=1008；工作流计数 U=2 / A=8 | 同接口按身份出不同数据 ✓ |

### 客户端镜像（可篡改，但不构成真实权限——见报告 03）
| 因素 | 位置 | 作用 |
|---|---|---|
| `isAdmin` | IDB `DBFetch/b50d8804` **且** LS `__system_config__`（双份镜像） | 全局管理员布尔 |
| 菜单树 | IDB `90bf918a`（A≈130KB / U≈27KB） | 菜单节点级呈现 |
| 页面清单 | IDB `b9bb337d`（A 99 页 / U 7 页，含 route/isEnabled/sort） | 路由级呈现 |
| 导航入口 | IDB `ed312510`（`admin__sys` 等入口 code） | 顶部入口呈现 |

### 会话与传输通道
| 因素 | 证据/机制 | QuickLogin 对策 |
|---|---|---|
| Bearer 令牌 | 每请求 `Authorization`；DNR 强制改写为绑定账号令牌 | AUTH 平面（2.5+） |
| Cookie（含身份类） | 登录时点快照回放；**3.7.2 起剔除身份类 cookie**（真实 jar 残留 token 被打包回放=真实环境覆盖根因） | COOKIE 平面（3.6/3.6.1/3.7.2） |
| WAF 会话 | `HWWAFSESID` 每标签独立签发（`2c0199…`/`ed91abb…`/`56a57a60…`），随快照回放；服务端视为过期即重发（实测 11 秒内 4 个新值） | 随 COOKIE 平面按账号隔离 |
| 设备指纹 | `__device_fp__` 命名空间隔离（存储平面）；多账号同指纹的服务端合并风险未复现 | 存储平面（2.6+） |
| HTTP 缓存 | URL 级全 profile 共享 → `_qlck=t<tabId>` 分区 | CACHE 平面（3.5） |
| 站点 SW/CacheStorage | register 拦截 + 命名空间 + match miss | 第五平面（3.5） |
| IndexedDB | origin 共享、缓存 `isAdmin`+菜单+页面+导航 → 曾是四象限泄漏载体 | 第六平面（3.7） |

## 二、影响「账号安全」的因素

| 因素 | 实测发现 | 风险评估 |
|---|---|---|
| 令牌时效 | JWT `exp` 存在（约 2h 量级），过期需重登 | ✅ 正常 |
| 单设备登录 | JWT `isEnableSingleDeviceLogin:"False"` | ⚠ 未启用：令牌可多端并存，泄露后无法互踢 |
| **读接口权限过滤** | 对象元数据(936条)、字段定义、**部署配置包清单**、工作流计数等管理侧 GET 对普通账号全部 200 | ⚠ **管理侧读接口未按用户权限过滤** → 信息泄露面（仅读，未测写操作——具破坏性，明确不测） |
| 密码策略 | `__login_config__`：最短 6 位、第三方 SSO 启用、可配置多项策略 | 常规 |
| 客户端权限镜像 | `isAdmin`/菜单/页面/导航在 IDB+LS 可任意篡改 | 低（仅影响本机呈现，服务端按 GUID 判定；见报告 03 五轮实验） |
| WAF 行为 | 会话 id 频繁轮换 + 按标签独立 | ✅ 无跨标签身份黏连 |

## 三、结论

1. **权限的真实边界在服务端**：细粒度（菜单/对象/字段）配置不落客户端，逐请求判定；客户端 IDB/LS 里的全是「呈现镜像」。
2. **短板在管理侧读接口**：未按账号权限过滤，普通账号可读取管理配置数据（含部署包信息）——建议平台侧为管理类 GET 增加权限注解。
3. **单设备登录未启用**是令牌泄露场景下的最大放大器。
