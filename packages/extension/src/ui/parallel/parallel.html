本地 / 云端

本地：账号存在这台电脑的浏览器里，断网也能用；换一台电脑就没有。

云端：账号存在服务器上，换电脑登录就能用；断网时读不到（数据不会丢，网络恢复即可）。

切换：本地 → 云端会把本地账号合并上传（同站同名的以最后修改时间较新的为准）； 本地数据不会被删除，随时可以切回来。
